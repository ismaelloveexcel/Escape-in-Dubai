# Escape-in-Dubai
Final Game

## Description
An interactive escape room game set in Dubai. You wake up in a luxurious hotel room and must find your way out by solving puzzles and exploring your surroundings.

## How to Play
1. Open `index.html` in your web browser
2. Read the story text and make choices by clicking the buttons
3. Collect items in your inventory
4. Solve puzzles related to Dubai to escape the room
5. Goal: Find the keycard and escape before your flight!

## Game Features
- Interactive story-driven gameplay
- Inventory system
- Dubai-themed puzzles and scenarios
- Beautiful UI with gradient backgrounds
- Replay functionality

## Hints
- Pay attention to dates and landmarks mentioned in Dubai
- The safe code is related to a major Dubai event
- Explore all areas before trying to escape
- Items in your inventory are important!

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
